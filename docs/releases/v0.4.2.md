## love-mini 0.4.2

### Install

With Port Store 1.3.0 or later it updates by itself. By hand: unzip **love-mini-0.4.2.zip** to
the root of the SD card.

### Fixed

- A game whose profile replaces some of its files (`files`) could not start a thread from a
  file (`love.thread.newThread("x.lua")`): "bad argument #2 ... (string expected, got nil)".
  Balatro stopped there at its start. love-mini's stand-ins for `love.filesystem.read` and
  `newFileData` now pass a game's arguments on exactly as they came.
- `tests/scenes/profile`: a scene that checks a profile's changes (`env`, `lua`, `edits`,
  `files`) together with threads and file data.
