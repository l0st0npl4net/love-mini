## love-mini 0.4.3

### Install

With Port Store 1.3.0 or later it updates by itself. By hand: unzip **love-mini-0.4.3.zip** to
the root of the SD card.

### Fixed

- Balatro was killed at its start (out of memory, `love exited with code 137`). For the
  small screen, its fonts are made again at another size, and that read the Chinese,
  Japanese and Korean fonts too: 10-20 MB each, more than the Mini has. Now a font from a
  big file (over 512 KB) is read only when a game first uses it, and only one such file is
  read at all. Another big font is the default one of its size, and the log says so once.
  In Balatro the language list shows those languages' names in the default font.
- After a font that could not be loaded, memory is freed before the default font is made.
