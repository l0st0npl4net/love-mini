## love-mini 0.4.1

### Install

With Port Store 1.3.0 or later it updates by itself. By hand: unzip **love-mini-0.4.1.zip** to
the root of the SD card.

### New

- **Shaders that never read their texture** (a background a shader draws alone, on whatever
  sprite) are drawn as that sprite's shape in one colour: the colour the shader writes out, or
  one of the colours it is sent, instead of the sprite's picture stretched over the screen.
- A profile can name a shader by the file it was read from (`"resources/shaders/x.fs"`) and
  pick the uniform a flat shader's colour comes from.
