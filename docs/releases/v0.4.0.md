## love-mini 0.4.0

LÖVE 11.5 for the Miyoo Mini and Mini Plus under OnionOS: games made with LÖVE run without a
port for each.

### Install

With [Port Store](https://github.com/l0st0npl4net/PortStore-Catalog-MiyooMini) 1.3.0 or later:
install any game of the love-mini games catalog, and Port Store puts love-mini on the card
first. By hand: unzip **love-mini-0.4.0.zip** to the root of the SD card (it contains
`Roms/PORTS/...`).

Then **Ports → love-mini check** shows that picture, buttons and sound work; **love-mini
diagnose** checks it piece by piece if a game does not start (`Roms/PORTS/Games/love-mini/diag.txt`).

### What a game gets

- All of `love.graphics` drawn by the CPU (no GPU on the Mini), 8 pixels at a time where it
  can (NEON): images, text, canvases, sprite batches, particles, primitives, transforms,
  stencil, blend modes; the game's own screen size laid on the Mini's.
- The Mini's buttons as keys and as a gamepad; a cursor for mouse games and a screen keyboard
  for text.
- Sound through OnionOS's audioserver; long music streamed.
- Shaders: common ones stood in for, the rest drawn without.
- Profiles for games that need something adjusted, including games the player owns: a game
  adjusted as it loads (settings it reads, Lua edits, modules and files of the profile's own),
  its file never changed. Balatro on love-mini is the first (from the love-mini games catalog).

Sixteen games from GitHub were tried, most of them at 60 frames a second on a Mini Plus:
`docs/compatibility.md`.

### Known limits

- Full-screen shader effects (blur, glow, CRT), 3D meshes, `love.video` and touch are not
  there. Heavy games (SNKRX with many objects: about 15–20 frames a second) slow down.
- Tried on a Mini Plus only. Balatro is not yet tried on love-mini.
